## 语料口径

- 来源：**BGA《奥丁的盛宴》对局**，共 **1460 局**（挪威扩展 + 迷你扩展 1&2，二人局长局），2920 玩家样本（平局 25 局，各记 0.5 胜，全体样本胜率 50.0%）
- 五重过滤：二人局 / 分差 ≤ 50 / 无认输提前结束 / 7 轮完整长局 / 必含 mini2 收获标记
- 数据质量审计：21 岛 × 完整供应窗口（翻面表）11104 次拿岛零越界

## 统计口径

- **胜率** = 拿到该组件且获胜的场数 ÷ 拿到该组件的场数（平局记 0.5）；行尾显示为 `胜场/场数`
- **置信区间**：Wilson 95% CI（z=1.96）；「显著」徽标 = CI 不含 50%；n<10 标「数据不足」
- **相关非因果**：所有数字是行为与胜率的统计相关，混杂着玩家水平与局势，不构成出牌建议的唯一依据
- 岛屿分级：S = CI 下限 ≥ 52%；A = 胜率 ≥ 53%；B = 其余；C = CI 上限 ≤ 48%

## 各视图判定规则

| 视图 | 说明 |
|---|---|
| 岛屿 | 样本 = 本局拿过该岛的玩家；横轴统一 30-70% |
| 岛屿组合 | 两两共现 n≥30，榜单按组合胜率降序、**每岛最多出现 2 次**（贪心去重）；组合 lift = 组合胜率 − 两岛单拿胜率均值；行内青条 = 共现次数 |
| 手工工棚 | 仅统计 R1-4 建造；**选择率** = 该面出场 ÷ 该板块（含背面）总出场，两面合计 100%（双面配对：伐木工小屋↔马厩、军械库↔牛舍、隐士小屋↔冰窖、猎人小屋↔猪圈、石匠工棚↔养蜂小屋、纺纱坊↔捕鲸小屋） |
| 职业卡 | 出场次数滑块实时过滤（主榜默认 n≥10）；悬停看卡号/分值/效果摘要 |
| 骰子行动 | 胜者 vs 败者对比：使用率、人均次数、掷骰成功率。行动分类 = 骰型（d8/d12）+ 结算内容 + 失败补偿三重判定（案例已回验） |
| 移民 | 判定 = 纯银币支付且金额 = 当前轮数（大移民 = 同一行动内打出职业卡）；双饼图 + 胜负 Δ 对照表 |
| 皇冠 | 全局仅一块，主要经 d12 大打劫获得；口径 = 拿到皇冠的对局中持有者胜/负/平分布，无人拿到的局不计入 |
| 对立局 | 熊岛 vs 火地岛、罗弗敦 vs 马尔岛 两组分家对局的基本盘 + 第三方岛屿归谁的影响 |
